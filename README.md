# SDE IoT Landing Page

Landing page static, responsive, tanpa build step.

## Struktur
- `index.html` — halaman utama
- `styles.css` — seluruh styling
- `script.js` — mobile menu + form demo
- `assets/sde-logo.png` — logo SDE dari asset yang diberikan

## Publish
Upload semua file/folder ini ke hosting static seperti:
- cPanel / shared hosting
- Netlify
- Vercel
- GitHub Pages

Tidak perlu npm atau proses build.

## Sebelum production
1. Ganti `hello@your-sde-domain.com` di `index.html` dan `script.js`.
2. Ganti nomor WhatsApp/alamat pada footer.
3. Ganti copy produk, spesifikasi, dan CTA sesuai katalog SDE.
4. Hubungkan form ke CRM/backend jika ingin menyimpan leads.
